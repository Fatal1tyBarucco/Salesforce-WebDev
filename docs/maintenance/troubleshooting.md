# Troubleshooting

## Scraper Failure

### Symptoms - Scraper Failure

- HTTP timeout

- empty payload

- Salesforce response changes

### Actions - Scraper Failure

- validate Salesforce endpoint

- inspect HTML structure

- rerun GitHub workflow

- validate retry logs
